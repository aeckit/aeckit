# aeckit

This package is a placeholder to secure the `aeckit` namespace across package registries:

- **PyPI (`pip install aeckit`)**: For the AECKit Python CLI, please install [`aeckit-cli`](https://pypi.org/project/aeckit-cli/):
  ```bash
  pip install aeckit-cli
  ```

- **npm (`npm install aeckit`)**: For Drawings-as-Code (DaC) JavaScript/TypeScript libraries, please install the scoped `@aeckit` packages:
  ```bash
  npm install @aeckit/dac-solid @aeckit/renderer-svg @aeckit/dac-json-solver
  ```

Visit the [AECKit website](https://aeckit.com) or [GitHub repository](https://github.com/aeckit/aeckit) for more information.

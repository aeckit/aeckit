# aeckit

This package is currently a placeholder to secure the `aeckit` namespace on PyPI.

For the AECKit CLI, please install `aeckit-cli`:

```bash
pip install aeckit-cli
```

Visit the [AECKit website](https://aeckit.com) or [GitHub repository](https://github.com/aeckit/aeckit-cli) for more information.
